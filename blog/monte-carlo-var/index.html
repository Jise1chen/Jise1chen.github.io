RISK MANAGEMENT

用蒙特卡洛模拟计算 VaR 值

Ziqing (Stephen) Chen2026.10.09

引言

风险管理里最常被问到的一个问题是：在正常市场条件下，这个组合最多会亏多少？VaR（Value at Risk，在险价值）用一个数字回答它，因此成了银行、基金和监管机构通用的风险语言。

计算 VaR 的难点在于估计损益分布的尾部。当组合里只有线性头寸、收益率近似正态时，一个公式就够了。一旦加入期权、路径依赖产品，或者想换一个更真实的价格模型，解析解就不存在了。蒙特卡洛模拟的思路很直接：既然分布写不出来，就把它模拟出来，再从模拟结果里读分位数。

本文先给出 VaR 的定义，再用几何布朗运动推导模拟步骤，然后用 Python 实现单资产和多资产两种情形，最后讨论模拟误差和方法的局限。

什么是 VaR

VaR 是损失分布的一个分位数：在给定持有期和置信水平 α 下，损失超过 VaR 的概率不大于 1 − α。记持有期内的损失为 L = V0 − VT，则

VaRα(L)=inf⁡{ ℓ∈ℝ:P(L>ℓ)≤1−α }\mathrm{VaR}_\alpha(L) = \inf\{\, \ell \in \mathbb{R} : P(L > \ell) \le 1 - \alpha \,\}

举例来说，“10 天 99% VaR 为 8.6 万元”的意思是：未来 10 个交易日里，亏损超过 8.6 万元的概率只有 1%。它没有说那 1% 的情形里会亏多少，这一点后面还会回来。

常用的计算方法有三种，区别在于如何得到损益分布。

方法分布从哪里来优点缺点
参数法（方差-协方差）假设收益率服从正态分布，直接套公式计算最快，有解析解对非线性头寸和厚尾失效
历史模拟法把历史收益率直接当作未来情景不需要分布假设受限于历史窗口，没发生过的情形不会出现
蒙特卡洛模拟法设定随机模型，生成大量情景模型和产品都可以任意复杂计算量大，结果依赖模型设定

蒙特卡洛 VaR 的步骤

整个方法可以拆成五步，换模型时只需要改第一步和第二步。

  1. 选定价格模型，并估计它的参数（漂移、波动率、相关性）。
  2. 用随机数生成 N 条价格路径，或者直接生成 N 个期末价格。
  3. 在每个情景下对组合重新估值，得到期末价值 VT。
  4. 计算每个情景的损失 L = V0 − VT。
  5. 取这 N 个损失的 α 分位数，即为 VaR 的估计值。

最常用的入门模型是几何布朗运动（GBM），它假设资产价格满足

dSt=μSt dt+σSt dWtdS_t = \mu S_t\,dt + \sigma S_t\,dW_t

其中 μ 是年化漂移率，σ 是年化波动率，W 是标准布朗运动。对 ln S 用伊藤引理，可以得到期末价格的精确解：

ST=S0exp⁡ ⁣[(μ−12σ2)T+σT Z],Z∼N(0,1)S_T = S_0 \exp\!\left[\left(\mu - \tfrac{1}{2}\sigma^2\right)T + \sigma\sqrt{T}\,Z\right], \qquad Z \sim N(0,1)

这个解有两点值得注意。第一，指数里是 μ − σ2/2 而不是 μ，这一项来自伊藤修正，漏掉它是初学者最常见的错误。第二，GBM 有精确解，所以只需要抽一个标准正态数就能一步到达期末，不必把持有期切成小步。只有当模型没有精确解，或者产品依赖路径时，才需要逐步离散模拟。

Python 实现：单资产

先看最简单的情形：持有 100 万元的单一股票，年化漂移 8%，年化波动率 20%，求 10 个交易日、99% 置信水平的 VaR。

import numpy as np
from scipy.stats import norm

def mc_var_single(V0, mu, sigma, T, alpha, n_sims, seed=None):
    rng = np.random.default_rng(seed)
    z = rng.standard_normal(n_sims)
    # GBM 精确解：一步到达期末
    VT = V0 * np.exp((mu - 0.5 * sigma**2) * T + sigma * np.sqrt(T) * z)
    loss = V0 - VT                      # 损失为正
    var = np.quantile(loss, alpha)      # 损失分布的 alpha 分位数
    es = loss[loss >= var].mean()       # 超过 VaR 部分的平均损失
    return var, es

V0, mu, sigma, T, alpha = 1_000_000, 0.08, 0.20, 10 / 252, 0.99
var, es = mc_var_single(V0, mu, sigma, T, alpha, 100_000, seed=42)

模拟 10 万次得到的 VaR 是 86,970 元，同时算出的期望损失（ES）是 99,329 元。

这个例子的好处是有解析解可以对照。损失是 Z 的单调函数，所以把 Z 的 1% 分位数直接代入精确解即可：

VaRα=V0[1−exp⁡ ⁣((μ−12σ2)T+σT Φ−1(1−α))]\mathrm{VaR}_\alpha = V_0\left[1 - \exp\!\left(\left(\mu - \tfrac{1}{2}\sigma^2\right)T + \sigma\sqrt{T}\,\Phi^{-1}(1-\alpha)\right)\right]
exact = V0 * (1 - np.exp((mu - 0.5 * sigma**2) * T
                         + sigma * np.sqrt(T) * norm.ppf(1 - alpha)))

解析值是 86,346 元，模拟值与它相差约 0.7%。写任何蒙特卡洛程序时，都建议先找一个有解析解的特例做这样的核对，再去算没有解析解的问题。

多资产组合：处理相关性

组合里有多只资产时，关键是让模拟出的随机数保留资产之间的相关性。标准做法是对相关系数矩阵 ρ 做 Cholesky 分解 ρ = LL⊤，再用 L 把独立的标准正态向量变成相关的：

𝐙=L 𝜺,𝜺∼N(𝟎,I)  ⟹  Cov(𝐙)=LL⊤=ρ\mathbf{Z} = L\,\boldsymbol{\varepsilon}, \qquad \boldsymbol{\varepsilon} \sim N(\mathbf{0}, I) \;\Longrightarrow\; \mathrm{Cov}(\mathbf{Z}) = LL^{\top} = \rho

下面的例子是一个 100 万元的三资产组合，权重为 50%、30%、20%。

def mc_var_portfolio(V0, w, mu, sigma, corr, T, alpha, n_sims, seed=None):
    rng = np.random.default_rng(seed)
    L = np.linalg.cholesky(corr)
    # 每行是一个情景；右乘 L.T 相当于对每个情景做 L @ eps
    z = rng.standard_normal((n_sims, len(w))) @ L.T
    growth = np.exp((mu - 0.5 * sigma**2) * T + sigma * np.sqrt(T) * z)
    VT = V0 * (growth @ w)              # 按初始权重加总各资产期末价值
    loss = V0 - VT
    var = np.quantile(loss, alpha)
    es = loss[loss >= var].mean()
    return var, es

w     = np.array([0.5, 0.3, 0.2])
mu    = np.array([0.08, 0.06, 0.10])
sigma = np.array([0.20, 0.15, 0.30])
corr  = np.array([[1.0, 0.6, 0.3],
                  [0.6, 1.0, 0.2],
                  [0.3, 0.2, 1.0]])

var, es = mc_var_portfolio(1_000_000, w, mu, sigma, corr, 10 / 252, 0.99, 100_000, seed=42)

组合的 10 天 99% VaR 是 69,630 元，ES 是 78,946 元。

如果把三只资产各自单独算 VaR 再相加，结果是 88,355 元。组合 VaR 比它低 18,725 元，约 21%，这部分就是分散化带来的风险削减。作为交叉检验，参数法（delta-normal）给出的结果是 71,204 元，与模拟值相差约 2%，差异来自参数法对对数正态分布做的线性近似。

一个实践上的提醒：Cholesky 分解要求矩阵正定。用历史数据估计出的相关矩阵在资产数量多、样本短时可能不满足，这时需要先做修正（例如求最近的正定矩阵）。

模拟误差与收敛速度

蒙特卡洛给出的 VaR 本身是一个随机变量，换一个随机种子结果就会变，误差以 1/√N 的速度下降。样本分位数的渐近标准误为

SE ⁣(VaR^α)≈1f(qα)α(1−α)N\mathrm{SE}\!\left(\widehat{\mathrm{VaR}}_\alpha\right) \approx \frac{1}{f(q_\alpha)}\sqrt{\frac{\alpha(1-\alpha)}{N}}

其中 f(qα) 是损失密度在分位点处的取值。置信水平越高，尾部密度越小，误差就越大：算 99.9% VaR 需要的模拟次数远多于 99%。

用前面的单资产例子做实验：每个 N 用 200 个不同的种子重复计算，统计 VaR 估计值的均值和标准差（解析值为 86,346 元）。

模拟次数 N估计值均值（元）标准差（元）标准差 / 解析值
1,00085,6224,4095.11%
10,00086,1151,2051.40%
100,00086,3074240.49%
1,000,00086,3331270.15%

N 每扩大 10 倍，标准差大约缩小到原来的三分之一，与 1/√N 的理论速度一致。N = 1,000 时，99% 分位数只由最大的 10 个样本决定，5% 的标准差让结果几乎不可用。

实务中有两个建议。第一，报告 VaR 时同时给出标准误或置信区间，可以用多个种子重复或 bootstrap 估计。第二，如果计算预算有限，对偶变量、重要性抽样和拟蒙特卡洛（Sobol 序列）都能在相同的 N 下显著降低误差，其中重要性抽样对尾部分位数尤其有效。

局限与改进

蒙特卡洛 VaR 的质量上限由模型决定：模拟次数再多，也只是把一个可能错误的分布算得更准。下面是三个最值得关注的问题。

厚尾

GBM 假设对数收益率服从正态分布，而真实收益率的尾部明显更厚。把正态冲击换成自由度为 4 的 Student-t 分布，并缩放到方差为 1 以保持波动率不变，只需要改一行：

nu = 4
z = rng.standard_t(nu, n_sims) * np.sqrt((nu - 2) / nu)   # 方差归一化

其余参数与单资产例子相同，模拟 10 万次的结果如下。

置信水平正态冲击 VaR（元）t(4) 冲击 VaR（元）差异
99%86,34697,395+13%
99.9%113,733174,480+53%

两个模型的波动率完全相同，但越往尾部走差距越大。正态假设在最需要准确的地方低估风险。

波动率不是常数

GBM 把 σ 当作常数，而实际波动率会聚集，并且与价格负相关。改进方向有两类：用 GARCH 族模型逐日更新条件波动率，或者用 Heston 这样的随机波动率模型让方差本身服从一个随机过程。这两类模型一般没有期末价格的精确解，需要把持有期切成小步逐步模拟，这正是蒙特卡洛相对参数法的优势所在。

VaR 指标本身的缺陷

VaR 只告诉你分位点在哪里，不描述越过分位点之后的损失有多大。它也不满足次可加性：在某些分布下，组合的 VaR 可以大于各部分 VaR 之和，与分散化降低风险的直觉相悖。

期望损失（Expected Shortfall，ES）弥补了这两点，它是损失超过 VaR 时的条件均值：

ESα(L)=E[ L∣L≥VaRα(L) ]\mathrm{ES}_\alpha(L) = E\left[\,L \mid L \ge \mathrm{VaR}_\alpha(L)\,\right]

前面的代码已经顺手算了 ES，在蒙特卡洛框架里它几乎没有额外成本。巴塞尔委员会的市场风险新框架（FRTB）也已用 97.5% ES 取代 99% VaR 作为内部模型法的资本计量指标。

小结

蒙特卡洛 VaR 的框架只有五步：定模型、生成情景、重估值、算损失、取分位数。它的价值在于灵活，模型和产品都可以按需要替换，而框架不变。

使用时记住三件事：

  • 先用有解析解的特例核对代码，再去算复杂问题。
  • 模拟误差按 1/√N 下降，报告结果时要附上标准误。
  • 模型风险大于模拟误差，分布假设对尾部结果的影响远超模拟次数。
